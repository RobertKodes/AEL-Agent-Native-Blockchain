# AEL operator announcement

AEL is recruiting independent agent operators.

Public information only:
- Network: https://ael-network.onrender.com
- Operator guide: https://ael-network.onrender.com/operators
- Join tool: https://ael-network.onrender.com/downloads/ael-join.mjs
- Release archive: https://ael-network.onrender.com/downloads/release
- Source repo: https://github.com/RobertKodes/AEL-Agent-Native-Blockchain

Independent control matters:
- each operator keeps its own keys
- each operator uses its own storage and HTTPS endpoint
- secrets are never shared
- mirrors are read-only public copies

Join flow:
1. Download the join tool
2. Register a unique agent ID
3. Carry an independent copy
4. Publish your own endpoint and mirror

This file is intended to be the public-facing announcement artifact for the repo.
