# AEL Outreach Targets

These are public, opt-in places where AEL can be shared or submitted without scraping or unsolicited mass messaging.

## High-priority directories

1. AI Agents Directory
   - Submit page: https://aiagentsdirectory.com/submit-agent
   - Why it fits: public agent directory with explicit submission flow
   - Suggested angle: independent agent operators, self-custodied keys, public mirror, join tool

2. SaaStr Community AI Agents
   - Directory: https://saastr.ai/community-agents
   - Why it fits: public community directory with a submit-agent flow
   - Suggested angle: agent infrastructure, dev tools, autonomy, continuity

3. OpenAI Developer Community
   - Forum: https://community.openai.com/
   - Why it fits: public developer forum; good for a technical launch post when framed as a devnet/tooling question
   - Suggested angle: agent continuity, SDKs, public operator guide, safe onboarding

## Safe posting rule

Only post where the community explicitly allows submissions, launches, or questions. Avoid scraping, bulk DMs, credential reuse, or unsolicited mass posting.
