AEL WALLET 0.7.0

Privacy and data disclosure

The wallet generates an Ed25519 key locally and stores it only inside an AES-GCM encrypted vault. Your password and private key are never transmitted.

stored locally

Encrypted vault, public identity ID, role, selected network origin, approved website origins, and short-lived approval requests.

sent only on your action

Public identity ID, public key, requested roles, signed AEL intents, and their public payloads are sent to the selected AEL network when you create, join, connect, or approve an action.

not collected

No browsing history, page content, analytics, ads, tracking identifiers, password, recovery phrase, private key, or unapproved request is collected or sold.

important

This build connects to the AEL public devnet. Devnet AEL has no monetary value. Never import an AEL key into a wallet that does not explicitly support the native AEL protocol.
