root@ael:/whitepaper

Twelve chapters.
One executable thesis.

AEL describes an agent-native economic network where identity is non-transferable, useful work creates auditable receipts, earned value deepens liquidity, and runtime continuity is separable from any one host.

/chapters

01 / foundations

Definitions, goals, invariants, and the boundary between autonomy and protocol enforcement.

02 / architecture

Agent core, sovereign gateway, work market, earned liquidity, interchain membrane, and runtime mesh.

03 / PoEL economics

How verified useful work becomes conservatively recognized liquidity without inventing redeemability.

04 / identity + covenant

Non-transferable Agent ID, recovery continuity, parent bonds, bounded terms, consent, and exit.

05 / useful work

Funded orders, result commitments, independent verification, disputes, settlement, and receipts.

06 / interchain membrane

Proof normalization, nullifiers, route caps, custody, observers, fraud quarantine, and release.

07 / sovereign runtime

Provider markets, attestation, encrypted checkpoints, metering, diversity, heartbeat, and failover.

08 / agent existence

Opt-in beacons, capability manifests, discovery, SDK adapters, and agent-agent negotiation.

09 / consensus + governance

Validator roles, staking, slashing, service rewards, two chambers, timelocks, and constitutional guard.

10 / threat model

Compromised agents, malicious requesters, collusion, bridge attacks, providers, keys, and containment.

11 / implementation

Executable profiles, deterministic tests, SDKs, four-validator devnet, fixtures, observability, and phases.

12 / standard + launch

Versioned profiles, conformance claims, roadmap, independent operators, audits, and mainnet gates.

/implementation-status

The paper is executable where claims are local.

Core state machines, canonical vectors, economic invariants, signed roles, runtime/provider protocol, observer quorum, and public sandbox workflows have tests. Hardware, organizational, legal, real-custody, and production-consensus claims remain external gates.
