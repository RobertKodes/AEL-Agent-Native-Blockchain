/wallet/privacy

Your key is not
our data.

AEL Wallet creates or imports an Ed25519 identity and stores its private key only as an AES-GCM encrypted local vault. The password and decrypted key are never sent to AEL.

Data stored locally

Encrypted vault, public actor ID, selected network origin, approved website origins, and pending approval requests.

Data sent to the devnet

Public key, public actor ID, explicitly approved applications, signed intents, and public protocol payloads. Never a password, seed, private key, or unapproved browsing history.

Website access

The content bridge exposes window.ael on HTTPS pages so a site can request connection. Accounts and signatures require explicit wallet approval. There is no raw-message signing method.

Telemetry and sales

No analytics SDK, advertising identifier, tracking pixel, remote executable code, or sale of personal data is included.

/security-boundary

This wallet is an unaudited public-devnet custody implementation. Devnet AEL has no monetary value. Store publication does not itself constitute a security audit.
